## 🚀 Cách chạy chương trình
### 1. Clone repository
```bash
git clone https://github.com/nhminh107/AppliedMathematics.git
cd AppliedMathematics
```

### 2. Runfile
Dùng lệnh như sau: 
```bash
python -m Part<i>.<file_name>
```
Trong đó i là 1/2/3; file_name là tên file muốn chạy
